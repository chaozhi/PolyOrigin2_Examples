Haplotype reconstruction for a real 3x3 half-diallel potato population

Chaozhi Zheng

Setup PolyOrigin

For parallel computation

using Distributed
nprocs() < 7 && addprocs(7-nprocs()) 
@info string("nworkers=", nworkers())
@everywhere using PolyOrigin

Set four worker processes on local machine. See the manual of addprocs for launching worker processes via the specified cluster manager or on remote machines via SSH. The processers consist of 1 main and 6 wokers: 3 repated phasing runs for each of two chromsomes.

The last line makes PolyOrigin avaiable on all processes.

For non-parallel computation

using PolyOrigin

run polyOrigin

chrsubset = 1:2
outstem = "potato4x_F1_out"

@time phasedgeno, polyancestry, joinedancestry = polyorigin(genofile,pedfile;
    isphysmap=true,
    recomrate=1.25,
    chrsubset,
    isparallel=true,
    outstem
)

The keyargs isphysmap and recomrate transform the input physical map (positions in base pairs) into genetic map with speficied constant recombation rate. isparallel specifies if computations are parallel among chromosomes, and outstem specifies the stem of output files.

The returned polyancestry from polyorigin has been saved.
